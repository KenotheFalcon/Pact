## 2024-05-03 - Password Input State Toggle & Meter Accessibility
**Learning:** Found a pattern where interactive state toggles (like password visibility) were hidden from keyboard users via `tabIndex={-1}` and lacked state-announcing ARIA attributes (`aria-pressed`). Additionally, dynamic visual indicators (like password strength bars) lacked the semantic `role="meter"` and `aria-live` regions, leaving screen reader users without critical feedback during form interaction.
**Action:** Removed `tabIndex={-1}` and added proper focus rings, `aria-label`/`aria-pressed`, and `aria-hidden` on decorative icons for state toggles. Added `role="meter"`, `aria-valuenow/min/max` and `aria-live="polite"` for text readouts on dynamic visual indicators. Added to memory to ensure future similar UI components include these attributes.
