## 2024-11-20 - Password Input with Strength Meter Accessibility
**Learning:** Adding a strength meter to a password input creates dynamic content that must be explicitly communicated to screen readers. Relying solely on visual cues (colors, bars) excludes visually impaired users. Furthermore, interactive elements like toggle buttons often lack keyboard accessibility if explicitly set to `tabIndex={-1}`.
**Action:** For all future password toggles, ensure `aria-label`, `aria-pressed`, and visible focus rings (`focus-visible`) are implemented, while hiding the decorative icons via `aria-hidden="true"`. For dynamic strength meters, use `role="meter"` with `aria-valuenow`/`min`/`max` on the visual bar, and `aria-live="polite"` on the textual readout so updates are announced.
