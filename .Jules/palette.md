## 2024-04-25 - Accessibility of Dynamic State Elements
**Learning:** `tabIndex={-1}` removes elements from keyboard navigation entirely, breaking accessibility for interactive elements like state toggles (e.g., password visibility buttons). Furthermore, visual indicators like password strength meters require ARIA roles (`role="meter"`) and live regions (`aria-live="polite"`) for screen reader support.
**Action:** When implementing interactive elements like password toggle buttons, ensure they have proper focus styles (`focus-visible:outline-none focus-visible:ring-2`), remove any negative `tabIndex` attributes, and use appropriate ARIA labels and pressed states. For dynamic visual representations, use `role="meter"` with `aria-valuenow`, `aria-valuemin`, and `aria-valuemax` alongside a polite aria-live textual readout.
