## 2026-05-10 - Accessible Dynamic Visual Indicators and State Toggles
**Learning:** When building complex form inputs like password fields with visual strength indicators and visibility toggles, interactive elements must receive focus and have clear accessible names (avoiding `tabIndex={-1}` on interactive icons/buttons). Furthermore, dynamic visual bars (like password strength) must be exposed as `role="meter"` with `aria-valuenow/min/max` values, and any dynamic text feedback must use `aria-live="polite"` so screen readers announce changes as users type.
**Action:** Always verify that state toggles have `aria-pressed` and `aria-label`, while decorative icons within them use `aria-hidden="true"`. Ensure that any visual progress or strength bars use standard `meter` or `progressbar` roles along with live regions for textual readouts.
