## 2024-05-24 - Add Tooltip and Accessibility to Password Strength Input Toggle
**Learning:** For icon-only action buttons like a password visibility toggle, removing `tabIndex={-1}` is essential to ensure they are accessible via keyboard navigation. Sighted users also benefit significantly from having a Radix UI Tooltip wrap the icon to clarify its purpose, and it's an acceptable tradeoff to place `<TooltipProvider>` directly inside an isolated component if modifying the root app layout isn't feasible for a micro-UX improvement.
**Action:** Always ensure interactive elements are keyboard focusable and styled appropriately for focus rings (`focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-pact-green focus-visible:ring-offset-2`). Wrap standalone icons with a `Tooltip` for visual clarity while maintaining `aria-label` and `aria-hidden="true"` on the icon itself for screen readers.
