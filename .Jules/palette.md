## 2024-05-18 - Interactive Element Focus Rings and Semantics
**Learning:** The custom `PasswordInputWithStrength` component previously broke keyboard navigation completely for screen reader users by applying `tabIndex={-1}` on the show/hide password toggle button. The visual strength indicator also lacked programmatic semantics to map it to a progress bar or meter, making its state invisible to non-sighted users.
**Action:** When creating form inputs with nested state toggles (like password visibility), ensure the toggle is keyboard focusable and styled appropriately with focus rings (`focus-visible:ring-2`). Map dynamic visual indicators to their semantic equivalents (e.g. `role="meter"` for password strength, with `aria-live="polite"` for text feedback) to make the experience accessible and delightful for all users.
