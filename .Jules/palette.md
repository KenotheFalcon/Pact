## 2024-05-07 - Accessible state toggles and dynamic visual indicators
**Learning:** Using `tabIndex={-1}` on interactive elements blocks keyboard navigation, making features like password visibility toggles inaccessible. Furthermore, dynamic visual indicators like password strength meters need proper ARIA roles (`role="meter"`) and live regions (`aria-live="polite"`) to be understood by screen readers, otherwise they are purely visual and provide no context to visually impaired users.
**Action:** When creating state toggles, ensure they remain keyboard focusable with visible focus styles (`focus-visible:ring`), use `aria-pressed` for state, and `aria-label` for screen reader descriptions. Decorative icons within these buttons should be explicitly hidden with `aria-hidden="true"`. For dynamic visual feedback (like strength meters), apply `role="meter"` with appropriate `aria-valuenow/min/max` attributes to the bar, and `aria-live="polite"` to the text label so updates are announced dynamically.
