## 2025-03-26 - Add ARIA attributes and focus styles to PasswordInputWithStrength eye button
**Learning:** Icon-only action buttons (such as password visibility toggles) in this app sometimes lack proper keyboard accessibility (`tabIndex={-1}` was present) and screen reader information (`aria-label`, `aria-pressed`, `aria-hidden` on internal SVGs, screen-reader-only descriptive text). They also occasionally miss visible focus states (`focus-visible:ring-2`, etc.) and tooltip wrappers to clarify their purpose for sighted users, as per memory guidelines.
**Action:** When updating icon-only buttons, especially those that toggle state, ensure the button is keyboard focusable (remove `tabIndex={-1}`), add `aria-label`, `aria-pressed`, `aria-hidden="true"` on SVGs, and apply standard `focus-visible` Tailwind classes. Also, wrap them in a Radix UI Tooltip for better sighted user experience.
