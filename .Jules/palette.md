## 2024-05-15 - Password Input State Toggles and Strength Indicators
**Learning:** Found a pattern where state toggles (like password visibility) were using `tabIndex={-1}` making them inaccessible via keyboard, lacking proper ARIA labels/states (`aria-label`, `aria-pressed`), and visual focus styles (`focus-visible`). Additionally, custom visual strength indicators were visually functional but completely inaccessible to screen readers.
**Action:** When creating state toggles or dynamic indicators, ensure they do not block keyboard navigation, use `aria-pressed` to indicate active state, have robust `focus-visible` styles, and utilize `role="meter"` alongside `aria-valuenow`, `aria-valuemin`, `aria-valuemax`, and `aria-live="polite"` for non-interactive visual indicators to ensure screen reader compatibility.
