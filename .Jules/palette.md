## 2026-05-02 - Password Input Accessibility
**Learning:** Password visibility toggle buttons using `tabIndex={-1}` severely degrade keyboard accessibility by blocking navigation to the toggle. Furthermore, dynamic visual indicators like password strength meters without proper ARIA roles (e.g., `role="meter"`) or live regions (e.g., `aria-live="polite"`) are completely opaque to screen readers.
**Action:** When implementing interactive form controls like password inputs with visibility toggles and dynamic feedback, ensure all interactive elements are reachable via keyboard (removing `tabIndex={-1}`), provide clear visual focus indicators (`focus-visible:ring-2`), assign accurate `aria-label` and `aria-pressed` attributes, and use appropriate ARIA roles (`meter`) and live regions (`polite`) for dynamic visual feedback.
