## 2026-04-05 - Accessible password toggles
**Learning:** In 'src/components/ui/password-input-with-strength.tsx', a password visibility toggle used `tabIndex={-1}` alongside an absolute positioning layout, completely removing it from the keyboard focus order and rendering the feature inaccessible. Additionally, while 'src/components/ui/password-input.tsx' handled keyboard focus and screen reader labels (`aria-label`, `aria-pressed`) correctly, neither implementation provided visual context (tooltips) for sighted mouse users interacting with an icon-only button.
**Action:** Always ensure interactive elements like icon-only toggle buttons remain in the natural tab order (avoid `tabIndex={-1}`), have visible focus states (`focus-visible:ring`), and are wrapped in Radix UI `<Tooltip>` components to complement ARIA labels for a fully inclusive experience.
