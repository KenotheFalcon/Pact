## 2024-05-19 - Password Toggle and Strength Meter Accessibility
**Learning:** In the `PasswordInputWithStrength` component, using `tabIndex={-1}` on the show/hide password toggle effectively blocks keyboard-only and screen-reader users from interacting with it. Additionally, while the visual strength meter is clear to sighted users, it provides no context to screen readers without specific roles and ARIA live regions.
**Action:** Always ensure interactive toggles do not have restrictive tab indices and implement visible focus rings (`focus-visible`). For dynamic visual feedback like strength meters, always pair the visual element with `role="meter"`, `aria-valuenow/min/max`, and use `aria-live="polite"` on the text output so screen readers announce changes as users type.
