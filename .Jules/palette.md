## 2024-04-23 - Accessibility issue pattern: `tabIndex={-1}` on state toggles
**Learning:** Adding `tabIndex={-1}` to interactive elements like password visibility toggle buttons breaks keyboard navigation, making it impossible for users relying on keyboards to toggle the state. The intention might have been to prevent focus from getting trapped or distracting, but it critically harms accessibility.
**Action:** When implementing state toggle buttons within inputs (like password visibility or clear buttons), avoid `tabIndex={-1}`. Instead, ensure standard visible focus styles using utility classes like `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2`, provide clear `aria-label`, update state with `aria-pressed`, and hide decorative icons with `aria-hidden='true'`.
